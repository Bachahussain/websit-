# Hasina Rahimy — Personal Portfolio Website

A modern, elegant, and fully responsive personal portfolio website showcasing web development projects, UI/UX design work, technical skills, and interactive services.

## 🌟 Key Features

- **Responsive Design:** Seamless experience across desktop, tablet, and mobile devices.
- **Bilingual Support:** Full English & Dari (دری) translation with RTL/LTR dynamic layout switching.
- **Dark / Light Theme Toggle:** Customizable appearance with persistent theme memory.
- **Interactive Components:** Project filtering, interactive modals, animated skills tab, and direct contact form.
- **Floating Controls:** Quick access WhatsApp button, AI assistant chatbot drawer, and back-to-top navigation.

## 🛠️ Built With

- **HTML5:** Semantic markup and structure
- **CSS3:** Custom styling, CSS Grid, Flexbox, and GPU-accelerated keyframe animations
- **JavaScript (ES6+):** Client-side dynamic interactions, state management, and internationalization (i18n)
- **Boxicons & FontAwesome:** High-quality vector icons

## 🚀 How to Host on GitHub Pages

This website is a pure static web application and requires no server configuration:

1. Upload the files to your GitHub repository root folder.
2. In your repository settings, go to **Pages** (under Code and automation).
3. Under **Source**, select **Deploy from a branch**.
4. Select the `main` (or `master`) branch and the `/ (root)` folder, then click **Save**.
5. Your live portfolio URL will be generated automatically by GitHub Pages!
